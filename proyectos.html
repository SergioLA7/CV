Aventura y Destino (TFG)

HTML5 CSS3 JavaScript Juego TCG / RPG

Página web simulada de una plataforma informativa para un juego de cartas táctico medieval imaginario. Incluye secciones de cómo jugar, galería de cartas y posible login para tener usuario registrado (con capacidad de conexión a una base de datos donde guardar los usuarios y mantener un registro de victorias, derrotas y empates) con el que poder entrar y descargar el juego desde la propia página web.
